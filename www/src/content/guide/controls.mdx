# Controls

Keyboard and mouse only; the keys can't be changed yet. The same list is in the game under **Settings → Controls**.

## Driving

| Key | Action |
| --- | --- |
| <kbd>W</kbd> | Accelerate |
| <kbd>S</kbd> | Brake, then reverse |
| <kbd>A</kbd> | Steer left |
| <kbd>D</kbd> | Steer right |
| <kbd>Space</kbd> | Handbrake |
| <kbd>R</kbd> | Back on the road when stuck |

## Combat

| Key | Action |
| --- | --- |
| Click | Capture the mouse |
| Mouse | Aim the turret and the camera |
| Left button | Fire |

## Match

| Key | Action |
| --- | --- |
| <kbd>Esc</kbd> | Pause, and release the mouse |
| <kbd>Tab</kbd> | Scoreboard, while held |
| <kbd>F3</kbd> | Debug overlay (frame rate and the like) |

## Chat (online matches)

| Key | Action |
| --- | --- |
| <kbd>Enter</kbd> | Chat to everyone in the match; <kbd>Enter</kbd> sends, <kbd>Esc</kbd> cancels |
| <kbd>T</kbd> | Chat to your team (Team Deathmatch); <kbd>Tab</kbd> switches while you type |
| `/w name message` | Whisper to one player; `/r message` answers the last whisper |
| `/mute name` | Mute a player for the match; `/unmute name` undoes it |

While you type, your car is left alone: nothing you type drives it. A message is 200 characters at most, and 8 messages in 10 seconds.

## Custom lobbies

| Key | Action |
| --- | --- |
| <kbd>↑</kbd> <kbd>↓</kbd> | Choose a lobby in the list |
| <kbd>Enter</kbd> | Join it; in the waiting room, Ready (the owner: Start) |
| <kbd>C</kbd> | Create a lobby |
| <kbd>/</kbd> | Search the list |
| <kbd>T</kbd> | Chat to the lobby, in the waiting room; <kbd>Enter</kbd> sends |
| <kbd>Esc</kbd> | Back to the modes; in the waiting room, leave the lobby (it asks first) |

## Menus

| Key | Action |
| --- | --- |
| <kbd>↑</kbd> <kbd>↓</kbd> | Choose |
| <kbd>←</kbd> <kbd>→</kbd> | Change the choice: weapon in the garage; arena, bots, Practice or Classic on the arena screen |
| <kbd>Enter</kbd> | Select |
| <kbd>Esc</kbd> | Back |
| <kbd>N</kbd> | Patch notes, on the main menu |
| <kbd>Enter</kbd> or <kbd>Y</kbd> / <kbd>N</kbd> | Accept / decline a match found (Classic), over any screen, a practice match included |

Driving is on <kbd>W</kbd> <kbd>A</kbd> <kbd>S</kbd> <kbd>D</kbd> only; the arrow keys belong to the menus.

## Settings worth knowing

- **Graphics**: a quality preset (low, medium, high) and the resolution scale. If the frame rate drops, lower the scale first.
- **Camera**: mouse sensitivity and camera shake.
- **Sound**: separate volume levels.
